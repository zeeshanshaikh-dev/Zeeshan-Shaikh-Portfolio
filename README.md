# Zeeshan Shaikh | Portfolio

A personal portfolio website built to showcase my projects, skills, resume, and professional profile.

## Overview

This portfolio is designed to present:
- my background and interests
- key technical skills and tools
- project work and experience
- downloadable resume
- contact and social links

## Tech Stack

- React.js
- JavaScript
- Bootstrap
- CSS
- React Router
- GitHub Calendar
- React PDF

## Local Development

1. Install dependencies:
   npm install

2. Start the app:
   npm start

3. Open the app in your browser at:
   http://localhost:3000

## Build

To create a production build:

npm run build
